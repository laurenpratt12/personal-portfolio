# Lauren Pratt — Portfolio

## About This Project

This project is the starting point for my semester-long personal portfolio. It was created for the **4.7 Lab: Semantic HTML Portfolio Skeleton** and focuses on building a complete portfolio structure using semantic HTML before adding CSS.

The goal of the portfolio is to introduce myself as a Computer Science student at Michigan State University, showcase some of the projects I have worked on, and highlight the skills I am developing as I continue learning about programming and web development.

## Sections

The portfolio currently includes:

* **Navigation** — Links to the different sections of the page.
* **Hero/Introduction** — My name, major, university, and a short introduction.
* **About Me** — Information about my background and interests in Computer Science.
* **Skills** — Programming languages and technologies I have worked with.
* **Projects** — A showcase of projects I have created, including the L'Oréal Chatbot, Water Rescue game, NASA Space Explorer, and Intel projects.
* **Contact** — Links to my LinkedIn, GitHub, and email.
* **Footer** — Additional page information and copyright.

## Projects Featured

### L'Oréal Chatbot

A conversational chatbot built to answer product and beauty-routine questions using JavaScript and an API.

### Water Rescue

An interactive browser game created to raise awareness about access to clean water and charity: water's mission.

### NASA Space Explorer

A web application using NASA's public APIs to browse space imagery and information, including the Astronomy Picture of the Day.

### Intel Sustainability Timeline & Summit Check-In

Two interactive websites created for Intel, including a sustainability timeline and an event check-in experience.
